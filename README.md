# RKN Checker — проверка сайта на нарушения закона РФ

Сайт-чекер: пользователь вводит URL → ИИ анализирует страницу → выдаёт список нарушений и сумму потенциальных штрафов.

Стек: Next.js 15 + TypeScript + Tailwind CSS + Anthropic Claude API.

## Как запустить (для новичка)

### Шаг 1. Установить зависимости

В терминале (внутри папки `rkn-checker`):

```bash
npm install
```

Это скачает все библиотеки (займёт 1–2 минуты).

### Шаг 2. Запустить сайт

```bash
npm run dev
```

Откроется на http://localhost:3000

### Шаг 3. (Необязательно) Включить настоящий ИИ-анализ

Без ключа сайт работает в **демо-режиме** — показывает заранее заготовленный пример нарушений.

Чтобы включить настоящий анализ через ИИ:

1. Зарегистрируйся на https://console.anthropic.com
2. В разделе **API Keys** создай новый ключ (формат `sk-ant-api03-...`)
3. Открой файл `.env.local` в корне проекта
4. Вставь ключ:
   ```
   ANTHROPIC_API_KEY=sk-ant-api03-твой-ключ
   ```
5. Перезапусти `npm run dev` (Ctrl+C, потом снова `npm run dev`)

Теперь ИИ будет реально читать HTML каждого сайта и искать нарушения.

## Структура проекта

```
rkn-checker/
├── app/
│   ├── api/check/route.ts      ← API: принимает URL и возвращает результат
│   ├── components/
│   │   ├── CheckForm.tsx       ← форма ввода URL
│   │   ├── ResultDisplay.tsx   ← блок с результатом
│   │   └── OrderFixForm.tsx    ← форма «Заказать исправление»
│   ├── lib/
│   │   ├── laws.ts             ← база из 36 правил (15 категорий)
│   │   ├── types.ts            ← типы данных
│   │   ├── fetch-site.ts       ← загрузка HTML сайта
│   │   ├── claude.ts           ← обращение к ИИ
│   │   └── demo.ts             ← демо-результат без ключа
│   ├── layout.tsx              ← обёртка всех страниц
│   ├── page.tsx                ← главная страница
│   └── globals.css             ← стили
├── Закон_РФ.md                 ← человекочитаемая база законов
├── package.json
├── tailwind.config.ts
└── .env.local                  ← сюда положи ключ
```

## Что куда добавлять

- **Хочешь добавить новое правило проверки** → дописываешь объект в `app/lib/laws.ts`. ИИ автоматически начнёт его проверять.
- **Поменять заголовки** → `app/page.tsx`.
- **Поменять цвета** → `tailwind.config.ts`, секция `colors.brand`.
- **Подключить настоящую оплату/email-уведомления** → отдельные API-роуты в `app/api/`.

## Важно

- Ключ Anthropic — платный (примерно $3 за 1 млн токенов на Sonnet 4.5). Одна проверка сайта = ~$0.02–0.05.
- Файл `.env.local` НЕ попадёт в git (он в `.gitignore`).
- Сайт работает локально на твоём компьютере. Для деплоя в интернет нужен будет Vercel/Cloudflare Pages — это в следующий заход.
